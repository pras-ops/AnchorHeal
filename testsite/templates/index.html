Discrete Scenarios

  • v1: Baseline Standard page layout with initial selectors. Used to capture golden anchor baseline.
  • v2: Class Rename Class changes from .price-tag to .product-amount. Tests visual healing fallback.
  • v3: Layout Shift Injects banner pushing page elements down ~120px. Tests position delta tolerance.
  • v4: Drastic Re-Tree Tags, classes, and layout structures all change. Tests heavy blending survival.
  • v5: Ad Hijack / Decoy A decoy element steals the class .price-tag. Tests visual/text context disambiguation.
